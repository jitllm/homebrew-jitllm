# jitllm Homebrew tap

```sh
brew tap jitllm/jitllm
brew install --cask jitllm   # jitllm.app, with jitllm and jitllmd on your PATH
brew install jitllm          # the command-line programs only
```

The cask and formula are generated from each [jitllm release](https://github.com/jitllm/jitllm/releases) and updated automatically.
